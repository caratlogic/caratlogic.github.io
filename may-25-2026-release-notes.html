Release Notes

Faster inventory tally and search, instant PDF access, richer line item descriptions, memo media export, and price code support across inventory workflows.

May 25, 2026
01
📦
Enhanced

Improved Inventory Tally & Advanced Search

Inventory tally and advanced search workflows have been refined to provide faster scanning operations and more accurate inventory filtering across gems and diamonds.

  • Barcode scanner input now remains automatically focused during inventory tally operations — including after scan validation or error dialogs
  • Advanced search color filtering now supports both single and multi-select matching with improved result accuracy
  • Gem and diamond inventory searches now return more reliable results when filtering by color combinations
  • Backend filtering enhancements ensure consistent matching behavior across inventory and tally modules
Teams can now perform high-volume tally operations and advanced stock searches with fewer interruptions and more dependable results.

🧾
Enhanced

Instant PDF Open After Document Creation

Document workflows now support immediate PDF access after successful creation — reducing extra navigation and verification steps.

  • Added Confirm & Open support for:
🗎 Invoices
🗎 Proforma Invoices
🗎 Credit Notes
📝 Memo Out (Consignment)
  • Generated PDFs automatically open in a new browser tab after document creation
  • Backend PDF processing updated to ensure documents are instantly available for viewing and sharing
Teams can now create, verify, and share transaction documents faster without manually reopening generated records.
03
🧩
Enhanced

Flexible Description Column in Invoice & Memo PDFs

Invoice and memo out templates now support optional description visibility for cleaner and more customizable customer-facing documents.

  • Show or hide the Description column directly from PDF preview and print settings
  • Description visibility is supported across both invoice and memo out PDFs
  • Line item descriptions are now optional during document generation workflows
  • PDF rendering automatically adjusts based on template visibility settings
Businesses can now generate more minimal or more detailed transaction documents depending on customer and operational requirements.

💎
Enhanced

Richer Default Item Descriptions

Automatically generated line item descriptions now include additional inventory attributes for clearer and more informative transaction records.

  • Default descriptions now include details such as:
    • Origin
    • Treatment
    • Color
    • Cut
    • Related inventory attributes
  • Applies automatically when adding gems or diamonds with empty descriptions to invoices and memo outs
  • Frontend and backend description generation behavior is now fully aligned
Documents now provide richer inventory detail automatically — reducing repetitive manual description entry.

💰
Enhanced

Improved Cost & Selling Price Toggle Handling

Price toggle behavior has been refined to preserve edited pricing values while switching between cost and selling modes.

  • Cost price and selling price values are now maintained independently per line item
  • Switching pricing modes no longer overwrites manually edited values
  • Inventory pricing behavior remains consistent across transaction workflows
  • Backend price basis handling updated for more reliable price population
Teams can now switch pricing views more confidently without losing custom pricing adjustments.

New

Memo Out Media Export

Memo out transactions now support exporting all related certificates, images, and videos into a single downloadable ZIP file.

  • Export media for all memo out line items in one operation
  • ZIP files automatically organize content by product and media type
  • Includes certificates, images, and videos associated with inventory items
  • Download progress feedback added during export generation
Sharing consignment media with customers and partners is now faster and significantly more organized.

Enhanced

Improved Business Contact Details

Business contact detail pages have been reorganized to improve visibility and consistency across customer and company information.

  • Contact information is now grouped into dedicated sections including:
    • Personal
    • Company
    • Address
    • Additional Information
  • Improved display consistency for secondary email and phone numbers, business phone, VAT and tax details, verification status, and notes and referral information
  • Address formatting updated for cleaner presentation and easier review
Business contact records are now easier to navigate and better suited for sales, finance, and operational workflows.

New

Color Code Support in Inventory Settings

Inventory settings now support configurable color codes for better visual representation across gem and diamond inventory.

  • Added support for hex-based color codes within inventory attribute settings
  • Supports both shorthand and standard hex color formats
  • Inventory tables now display configured background colors for color attributes
  • Color codes can be managed directly from settings create and edit workflows
Teams can now visually identify inventory color attributes more efficiently across listing and inventory screens.

Price Code Support Across Inventory & Barcode Labels

Price codes are now supported throughout inventory workflows, imports, exports, and barcode label generation.

  • Added price code support for gem and diamond inventory records
  • Available across inventory forms, detail pages, and barcode configurations
  • Included in CSV and Excel import/export workflows
  • Price code fields can now be added to barcode and QR label templates
Price reference handling is now more flexible and better integrated into inventory and labeling operations.

Additional Improvements

Additional refinements have been introduced across transactions, reporting, inventory sorting, and PDF workflows.

  • Proforma invoice exchange rates are now preserved during final invoice conversion
  • VAT number display corrected within tenant PDF headers
  • Memo return PDFs and emails now support optional return date visibility
  • Business contact stock calculations now use transaction line-level data for improved accuracy
  • Added total carat sorting support across inventory listings
  • Price code support added to inventory Excel import and export workflows
These improvements continue to enhance accuracy, flexibility, and consistency across day-to-day inventory operations.
