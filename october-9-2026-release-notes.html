CaratLogic Inventory — Release Notes

This release adds Stock ID search to layouts, redesigns document detail pages with clearer payment, memo and quotation status, standardizes statuses across lists, and improves emails, forms and invoice cancellation.

October 9, 2026
01
🔍
Enhanced

Layout Search by Stock ID

Layout search now supports searching by the stock IDs of gems and diamonds contained within a layout.

  • Search layouts using Layout ID, Name, Description, or Stock ID
  • Searching by a stock ID returns all layouts containing that stone
  • Supports partial matching and case-insensitive searches
Teams can now locate layouts containing specific stones without manually checking individual layouts.
02
📄
Enhanced

Redesigned Document Detail Pages

Document detail pages have been redesigned to provide better visibility into financial summaries, document status, and key transaction information.

  • Redesigned detail pages for Invoices, Proforma Invoices, Quotations, Credit Notes, Memo Out, Memo Out Returns, Memo In, and Memo In Returns
  • New summary panel displays document amounts, status, dates, item count, currency, and applicable GST details
  • Document status is now displayed alongside the document number, with primary actions available directly in the header
  • Totals are displayed at the bottom of the items table, with payment details organized below
  • Customer and supplier cards now include a direct link to view the corresponding contact
  • Related documents, including payments, memos, and reference invoices, open in a new tab
Document details are now easier to review, with important information and frequently used actions available in one place.
03
💰
Enhanced

Improved Invoice Payment & Due-Date Visibility

Invoice detail pages now provide a clearer view of payment progress, outstanding balances, and payment deadlines.

  • Unpaid and partially paid invoices display the outstanding balance with a payment progress bar
  • Due-date countdown indicates when an invoice is due or how many days it is overdue
  • Paid invoices display the payment date and indicate whether payment was completed before or after the due date
  • Payment count is displayed with a direct link to the Payments section
  • Overdue invoices display a highlighted banner with the outstanding amount and due date
Teams can now track invoice payment status and follow up on overdue balances more efficiently.
04
📦
Enhanced

Improved Memo & Quotation Status Visibility

Memo and quotation detail pages now provide clearer visibility into outstanding items and document deadlines.

  • Memo Out displays returned, sold/invoiced, and outstanding carats, along with the settlement percentage
  • Memo In displays a countdown to the return due date
  • Quotations display a countdown to the validity expiry date
  • Memo Out item actions remain visible, with clear explanations when an action is unavailable
These improvements make it easier to track consignment movements, monitor return deadlines, and manage quotation validity.
05
🧾
Enhanced

Consistent Document Statuses Across Lists & Details

Document status labels have been standardized to provide a consistent view across listing and detail pages.

  • Invoice lists now display Overdue with the number of overdue days and identify partially paid invoices
  • Memo lists now use consistent Not Returned, Partially Returned, and Returned statuses
  • Memo In listings now display readable status labels instead of internal codes
  • Memo Out Returns actions are grouped into a single menu for viewing, downloading PDFs, and sharing
Document statuses and available actions are now easier to understand across transaction listings.
06
📧
Enhanced

Improved Email & Document Notifications

The document email workflow has been redesigned to provide clearer recipient information before sending.

  • Email dialogs now display the number of recipients added
  • Invalid email addresses are identified before sending
  • A clear note indicates that the document PDF link is included in the email
  • GST warnings are displayed prominently near the top of relevant document pages
These improvements help users review email recipients and document information before sharing them with customers.
07
🛠
Enhanced

Improved Forms & Dialogs

Forms and dialogs across the application have been updated for a more consistent user experience.

  • Updated dialog layouts and styling across the application
  • Inline validation messages now identify field-level errors more clearly
  • Bulk delete and archive operations provide results grouped by reason
  • Added a dedicated layout option for splitting parcels
  • Loading placeholders now better match the structure of the page being loaded
These refinements provide clearer feedback during data entry and inventory operations.
08
🧾
Enhanced

Invoice Cancellation Improvements

Invoice cancellation has been improved for invoices registered with an e-invoicing provider but not yet sent.

  • Eligible invoices can now be cancelled through the e-invoicing provider
  • The local invoice is cancelled only after the provider confirms the cancellation
  • If the provider rejects the cancellation, the local cancellation is reversed and an error message is displayed
This ensures invoice cancellation remains consistent between CaratLogic and the e-invoicing provider.
