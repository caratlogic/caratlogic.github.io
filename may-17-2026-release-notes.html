Release Notes

Smarter inventory search, Set stock type, dedicated layout management, refined archive workflows, and centralized partner stone tracking.

May 17, 2026
01
🔍
Enhanced

Custom Date Range in Advanced Search

Advanced inventory search now supports custom created-date filtering — making it easier to isolate stones added during a specific intake or listing period.

  • Filter gem and diamond inventory using a custom Created Date range directly from Advanced Search
  • Combine date filtering with existing criteria including carat, price, measurements, and more
  • Backend support for createdAtFrom and createdAtTo ensures accurate result matching across the selected period
Teams can now locate recently added or historically listed inventory faster — without manually navigating through unrelated stock.
02
📦
New

Set Stock Type for Gems & Diamonds

A new Set stock type is now available for gem and diamond inventory — purpose-built for grouped stones with explicit piece-based quantities.

  • Select Set as a stock type alongside Single, Parcel, and Pair during inventory creation and editing
  • Supports parcel-style behaviors including quantity tracking, split, and merge operations
  • Measurement ranges for sets follow the .to pattern for improved multi-stone representation
Sets provide a cleaner and more accurate way to model grouped inventory without relying on Parcel or Single classifications.
03
🧩
Enhanced

Dedicated Layout Management Module

Layouts are now managed through a dedicated module instead of being tied to inventory stock types — delivering a cleaner workflow for layout creation and trading operations.

  • Layout has been removed from the stock type dropdown across gem and diamond inventory forms
  • New Layout Management section under Inventory supports creating, editing, viewing, and duplicating layouts
  • Combine multiple gems and diamonds within a single layout with consolidated totals, media, and status tracking
Layouts can now be maintained and reused independently — without coupling layout logic to individual inventory records.
04
💎
Enhanced

Archive Handling Improvements for Gems & Diamonds

Archive workflows for gems and diamonds have been refined to better support invoiced and credited inventory scenarios.

  • Inventory linked to invoices and fully adjusted through credit notes can now be archived correctly
  • Improved archive validation prevents eligible stock from remaining unnecessarily active in inventory
Archive handling is now more aligned with real-world sales and return workflows across gems and diamonds.
05
🤝
New

Partner Stone Management

A dedicated Partner Management module now provides centralized tracking for partnership-based inventory across gems and diamonds.

  • Associate one or more business-contact partners with a gem or diamond using contribution amounts and profit percentages
  • Track company contribution, partner contribution, expenses, and profit-sharing details — including post-sale profit calculations
  • Search and filter partnership records by stock ID, partner, inventory type, and status with full add, edit, detail, and removal support
Partnership inventory is now managed in a single structured workspace — eliminating dependency on spreadsheets and manual tracking methods.
