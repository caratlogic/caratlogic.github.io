Inventory & Transactions — Release Notes

This release adds Excel upload for invoice and memo out line items, links certificate numbers to lab verification pages, simplifies diamond color requirements, renames intensity settings, and cleans up media when items are permanently deleted.

September 28–29, 2026
01
📤
New

Upload Invoice & Memo Out Line Items from Excel

You can now add many stones to an invoice or memo out at once from a spreadsheet.

  • An Upload items button is on the Invoice list, the Memo Out list, and the Create Invoice and Create Memo Out pages. On the create pages you need to select a customer first.
  • Download the template (add_line_items_template.xlsx). Item Type (gem or diamond) and Stock ID are required. Description, Quantity, Carats, Selling Price Per Carat and Total Price are optional.
  • An empty cell uses the stone's own value. If you give only a Total Price, the price per carat is calculated from it. If you give both prices, Selling Price Per Carat is used.
  • You review every row before anything is added. Rows are rejected if the stone is not found, is archived, or is not In Stock or on Memo Out. Duplicate rows and stones already on the document are skipped.
  • One document can hold up to 100 stones. When you go back to the page, everything you had already entered is still there.
02
🔗
New

Certificate Numbers Link to the Lab's Verification Page

Certificate numbers for GIA, GCAL and IGI now open the lab's report-check page in a new tab.

  • Works in the inventory list and on the detail page, for both gems and diamonds
  • Diamonds already had IGI links. Gems now have them too.
  • GCAL has been added to the list of certificate labs
03
💎
Changed

Diamonds: Color Grade or Fancy Color, Not Both

A diamond now needs only one of Color Grade (D–Z) or Fancy Color. Before, a Color Grade was always required, even for fancy-colored stones.

  • Applies to the add/edit form, bulk import and the API
  • The bulk import template always includes both the Color and Fancy Color columns. Each row needs a value in at least one of them.
04
⚙
Changed

Settings Renamed

  • Gem settings: Color Intensities is now Color Intensity
  • Diamond settings: Fancy Intensities is now Fancy Intensity
  • In the diamond inventory table, the Color Intensity column is now Fancy Color Intensity. If you had renamed this column yourself, your name is kept.
05
🗑
Changed

Media Is Removed When an Item Is Permanently Deleted

When a gem or diamond is permanently (hard) deleted, its images, videos, certificate files and uploaded custom-field files are also deleted from storage.

Files linked from outside CaratLogic are never touched. If the file cleanup fails, the item is still deleted.
