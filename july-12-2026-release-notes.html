Release Notes

Tenant-controlled email notifications, stronger CSV import validation, more reliable split inventory media, clearer currency handling, and consignment workflow improvements.

July 12, 2026
01
📧
New

Tenant-Controlled Email Notifications

A new Settings page lets each tenant enable or disable automatic customer emails for key consignment and invoice events.

  • New Settings → Email Notifications page to manage automatic customer emails
  • Per-event toggles for Memo Out Created, Cancelled, Partially Returned, and Returned
  • Invoice Created toggle reserved for future automatic sends
  • Automatic emails default to off and only send when the matching toggle is enabled
  • Manual Send Email actions always deliver, regardless of toggle settings
Tenants now control which automatic emails go out, while manual sends remain available whenever needed.
02
📄
Enhanced

Stronger CSV Import Validation

Import-column alias preferences are now validated to prevent conflicting mappings and import errors.

  • Aliases must be unique within each section
  • Validation rules adapt by module type
  • Improved schema support for string-array alias values
CSV imports are more reliable, with clearer validation before conflicting column aliases can cause issues.
03
📷
Enhanced

More Reliable Inventory Media on Split

Inventory media handling has been improved so split items retain their images correctly.

  • Media URLs are normalized in diamond and gem inventory API responses
  • Split inventory now copies media objects so child items keep their images
  • Description and notes have been removed from inventory search filters
Split inventory items now keep their media intact, reducing missing-image issues after stock splits.
04
💰
Enhanced

Clearer Currency Handling for PDFs & Emails

Currency conversion for PDFs and emails has been reworked for consistency between live and tenant exchange rates.

  • Exchange-rate retrieval supports a source option: live rates or tenant rates
  • PDF and email currency conversion now follow the same conversion logic
  • Invoice footer display data is aligned with the selected conversion source
  • Same currency behavior across emails and PDFs
Documents and emails now show currency amounts consistently, whether using live or tenant-configured rates.

📦
Enhanced

Consignment (Memo Out) Improvements

Consignment workflows now include better filtering, safer deletion rules, and partial-return email support.

  • Multi-select status filtering on consignment listings
  • Deletion limited to consignments in cancelled status
  • Partial-return notification email when some items remain outstanding
  • Rich-text notes normalized for cleaner email content
  • Share button removed from Consignment detail pages
Consignment management is safer and clearer, with better status control and improved return notifications.

🤝
Enhanced

Partner Stone Capital Contribution UX

Partner stone flows make capital contributions easier to enter, with clearer defaults and layout polish.

  • profitPercent is optional and defaults to 0
  • New capital contribution input with an amount-vs-percent toggle
  • Integrated into Add and Edit partner stone flows
  • Improved labels and layout for a clearer partnership setup experience
Partner stone setup is more flexible, especially when capturing capital contributions and profit-sharing details.

Credit Notes & Invoices

Detail page actions and display polish for credit notes and invoices.

  • Share button removed from Credit Note and Invoice detail pages
  • Uppercase display issue fixed
Financial detail pages are cleaner, with more consistent text display.

🏷
Enhanced

Exhibition Status Field Removed

The persisted exhibition status field has been removed end-to-end for a simpler exhibition data model.

  • Status field removed across migration, indexing, and application layers
  • Related enum, DTO, and service cleanup completed
Exhibition records are simpler and no longer carry a redundant status field.
