Inventory — Release Notes

This release adds configurable line descriptions for documents, bulk import templates built from each tenant's own settings, source tracking for Memo In inventory, wider audit history, and consistent country field names.

September 24, 2026
01
📝
Enhanced

Custom Line Description Configuration

Default item descriptions can now be configured directly from the Default Template settings.

  • Select up to 5 inventory fields to make up the line description for gems and diamonds
  • Fields can be selected and ordered independently for Invoices, Quotations, Memo Out, and Memo Returns
  • Supports standard inventory fields as well as custom fields
  • Empty values and “-” placeholders are automatically skipped, while certificate fields use the first available certificate value
  • Manually entered descriptions are always preserved and are never overwritten
Default descriptions now provide more flexibility while keeping manually entered customer-specific descriptions intact.
02
📊
Enhanced

Tenant-Specific Bulk Import Templates

Gem and diamond bulk import templates now automatically reflect each tenant's inventory configuration.

  • Download Template now generates the Excel template based on the tenant's own attribute settings
  • Dropdown values are populated using the tenant's configured inventory attributes
  • Custom fields are included in the generated template
  • Bulk imports now support importing values for custom fields
  • Custom field columns are matched and displayed during import validation
Bulk imports are now better aligned with each tenant's inventory setup, reducing manual template adjustments before importing data.
03
💎
Enhanced

Improved Memo In Tracking & Search

Memo In workflows now provide better visibility into the source of inventory and more flexible search options.

  • Gem and diamond detail pages now show whether the inventory originated from Memo In or Purchase
  • Source information includes a direct link to the related Memo In or Purchase record
  • Memo In search now supports Memo In Number, Supplier Name, Supplier Email and Stock ID
  • Search placeholder updated to indicate Stock ID support
Teams can now trace inventory back to its source and locate Memo In records using the information they already have.
04
🕒
Enhanced

Expanded Audit History

Audit history now captures changes to custom inventory fields and provides additional event information.

  • Changes to custom fields on gems and diamonds are now recorded during creation and editing
  • Audit entries now include event and customer information
  • Internal KYC workflow events are excluded from audit history
  • Relevant customer and contact events remain visible for users
Audit history now provides a more complete record of inventory and customer-related changes without exposing internal workflow events.
05
🔄
Enhanced

Standardized Origin & Manufacturing Country Fields

Inventory field names have been standardized across the platform to provide consistent terminology.

  • Origin / Origins is now displayed as Origin Country
  • Mine on diamond inventory is now displayed as Manufacturing Country
  • Updated across inventory tables, detail pages, filters, and column preferences
  • Changes also apply to barcode fields, role-based column restrictions, import templates, import aliases, dashboards, and document line items
Field naming is now consistent across inventory, reporting, imports, and customer-facing documents.
