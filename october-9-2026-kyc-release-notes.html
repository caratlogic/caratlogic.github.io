KYC Improvements — Release Notes

This release adds multiple file uploads per KYC field, file preview and image cropping, safer saving in Admin Fill KYC, one expiry reminder per document, and more reliable file handling for existing records.

October 9, 2026
01
📁
Enhanced

Multiple File Uploads for KYC Documents

KYC file upload fields now support up to 5 files per field, making it easier to submit documents that contain multiple pages or images.

  • Supports up to 5 files for File, Image, and Document with Expiry fields
  • Available in both the public KYC portal and Admin Fill KYC
  • Supports multiple files for documents such as passports, including front and back images
  • All files associated with a document share a single expiry date
KYC submissions can now accommodate multiple files for a single document without requiring separate fields.
02
🖼
Enhanced

KYC File Preview & Image Cropping

File preview and image handling have been improved to make document uploads easier to review before submission.

  • Preview uploaded files before submitting the KYC form
  • Images open in a dedicated cropping window
  • Reviewers can view all files uploaded under each field
  • Clicking a file downloads it using its original filename
Users can now review uploaded documents more easily, while reviewers can access individual files without losing their original filenames.
03
🔒
Enhanced

Safer KYC Updates in Admin Fill

Admin Fill KYC now saves changes only when the administrator submits the completed form.

  • File uploads and form edits remain local until Submit is clicked
  • All form changes and uploaded files are saved together
  • Incomplete edits no longer overwrite a contact’s previously submitted KYC record
  • The public KYC portal continues to save progress page by page
This prevents incomplete administrative edits from unintentionally replacing existing KYC information.
04
📧
Enhanced

Improved Document Expiry Reminders

Expiry reminder emails have been updated to handle documents containing multiple files.

  • Sends one expiry reminder per document field instead of separate reminders for each file
  • Uses the configured field label as the document name in reminder emails
  • Document expiry dates are shared across all files uploaded under the same field
  • Expiry dates are required for document-with-expiry fields and must be in the future
Expiry reminders are now more consistent and easier to understand when a document contains multiple files.
05
🛠
Enhanced

KYC File Handling & Compatibility

KYC file handling has been improved to ensure reliable uploads and continued compatibility with existing records.

  • Fixed file preview and removal actions to correctly identify recently uploaded files
  • Existing single-file KYC submissions continue to display and validate correctly
  • Previously submitted documents with expiry dates remain supported
  • Existing expiry reminder workflows continue to work without requiring data migration
These improvements ensure reliable file management while preserving existing KYC records and workflows.
