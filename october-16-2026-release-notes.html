Memo Out & Transactions — Release Notes

This release lets you edit open memo outs, creates a new memo out PDF after every change and keeps every earlier version for download, lets one invoice bill items from several memo outs, and adds a Stock ID filter to line items across transactions.

October 16, 2026
01
✏
New

Edit a Memo Out

Where: Memo Out list → row actions menu → Edit Memo Out, or a memo out's details page → actions menu → Edit Memo Out

You can now change a memo out after it has been created. The edit page looks like Create Memo Out, and the Memo Out Summary card updates the totals as you type.

What you can change

  • Carats, Quantity and Rate on any line that is still out
  • Service names and amounts
  • Return Date, Customer Discount (%) and Shipping Cost
  • Customer Notes and Additional Notes

Click Save changes. You'll see e.g. Memo out updated · PDF v2 generated and go back to the memo out.

Stock limits

  • You can raise carats or quantity only by what that stone still has in stock. If you go over, the field shows e.g. Only 1.25 left in stock.
  • Lowering carats or quantity puts the difference back in stock.
  • The stone's status updates to match. It shows Memo Out only when all of its carats are on memo, and In Stock otherwise.
⚠ What can't be edited. Returned and cancelled memo outs can't be edited. Lines that are fully returned or invoiced, and cancelled services, are shown but locked. You can't add or remove lines or services in an edit. If the memo out changes while you're editing (for example, a line is returned), you're asked to reload and try again.
02
📄
New

A New Memo Out PDF After Every Change

The memo out PDF is now regenerated whenever the memo out changes, so the PDF always matches what is on the memo. Each PDF shows its version under the memo details, e.g. Revision: v2.

  • A new version is created when you edit the memo out, return some or all items, or invoice items from it.
  • New memo outs start at v1. On memo outs created before this release, the existing PDF counts as v1 and the next change creates v2.
  • Emails and shared PDF links always use the latest version.
03
📤
New

Download Earlier Memo Out PDFs

Where: Memo out details page → Download, or Memo Out list → row actions menu → PDF

Every PDF version of a memo out is kept. The download menu lists the current PDF with a Latest badge, then Previous versions, newest first, each with its version number.

  • Downloaded files include the version in their name, e.g. MO-26-0142-v3.pdf.
  • Memo outs with a single-line PDF keep both PDFs for every version, e.g. MO-26-0142-single-line-v3.pdf.
  • A memo out that has never changed has only one PDF, and the menu looks the same as before.
You can always send a customer the exact memo they received earlier, even after the memo out has been edited, returned or invoiced.

🧾
New

Invoice Items From Several Memo Outs

Where: Create Invoice → Items → Add memo items

You can now bill items from several of a customer's memo outs on one invoice. Before, an invoice could only be created from one memo out at a time.

How it works

  • Choose the customer first. Add memo items then lists that customer's open memo outs.
  • Use Filter by stock ID or memo ID to find items. Tick single lines, or select every line on a memo at once. A memo's services can be added too.
  • Click Add to invoice. You can add items from more memo outs at any time, and mix them with stones picked from inventory.
  • Carats, quantity and rate on a memo line can be changed, up to what is still out on that memo.
  • Each memo line shows where it came from, e.g. From MO-26-0142, on the invoice review, details and edit pages.
  • When the invoice is created, each memo out it billed from is updated and gets a new PDF version.

Good to know

  • Lines already on the invoice are greyed out with the reason Already on this invoice. On a single-line invoice, lines of the other item type are greyed out too.
  • Changing the customer removes any memo lines you've added, since they belong to the previous customer's memos.
  • Add memo items is available on invoices only. Proforma invoices and draft invoices don't have it.

Filter Line Items by Stock ID

Line item tables now have a Filter by stock ID box in their header. Type all or part of a stock ID (not case-sensitive) and the list narrows as you type. If nothing matches, you'll see e.g. No items match stock ID “PO1147”.

Changed

All Line Items Shown in Full

Line items on details and review pages no longer sit in a fixed-height box with its own scroll bar. Every item is now listed in full, and the whole page scrolls as one.

  • Applies to Invoice, Proforma Invoice, Quotation, Credit Note and Memo Out details, and the invoice review page.
